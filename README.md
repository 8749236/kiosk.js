# tracemark（暂定名）

给每个支援者发一份带隐形编号的图。图被转卖或转载后，拿原图和泄露的图一比，就知道是谁那份流出去的。

- 改动极小：平涂区域每个像素最多变 1 级亮度，线条和纹理处最多 5 级。
- 识别时需要原图。作为交换，它扛得住转格式、压缩、缩放、裁剪、镜像翻转和局部遮挡。
- 核心库没有任何依赖，已编译成 WASM，有命令行和网页两种用法。

## 用法

```sh
cargo build --release

# 给 3 个支援者各出一份
tracemark embed page1.png "out/page1_{id}.png" --id 101 --id 102 --id 103 --key 我的密钥

# 发现盗图后
tracemark detect page1.png leaked.jpg --key 我的密钥
# Match: id 102
#   strength 31.4 sigma, 25% of the original present, alignment 0.99

# 图损坏得很厉害时，把发放过的编号给它，会更容易认出来
tracemark detect page1.png leaked.jpg --key 我的密钥 --id 101,102,103
```

编号是 0 到约 42 亿的整数；编号对应哪个支援者由你自己记录。`--key` 不填也能用，填了之后别人不知道密钥就读不出也伪造不了编号。输出请用 PNG；`detect` 加 `--json` 可得到机器可读的结果，认出人时退出码为 0。

## 网页版

`web/` 是一个纯静态页面：填密钥和支援者名单，拖入图片，下载每人一份的压缩包；发现盗图后在"查泄露"里拖入原图和可疑的图。图片只在浏览器里处理，不上传。

```sh
python3 -m http.server -d web 8000   # 然后打开 http://localhost:8000
./web/build.sh                       # 改了 Rust 代码后重新生成 web/tracemark.wasm
```

把 `web/` 目录原样放到任何静态托管（GitHub Pages、Cloudflare Pages）上即可。网页版里，编号由"密钥 + 名字"算出，同一个名字永远得到同一个编号；压缩包里附带 `名单.csv`。

## 原理

1. 编号加 16 位校验码共 48 位。把图按比例划成 48×48 格，每格归属其中一位，带一个由密钥决定的正负号。
2. 把这张正负格子图插值成平滑起伏，乘上幅度（平涂处 1 级，画面越复杂越大），用随机抖动取整后加到亮度上。
3. 识别时先把泄露图对齐到原图上（多尺度滑动匹配找出大致位置，再爬山微调，镜像也试），把原图缩到泄露图的分辨率后相减，扣掉整体色调变化，剩下的按格子取平均，再和每一位的正负号做相关。
4. 校验码通过才报编号，所以读错时得到的是"没读出"，不会指向无辜的人。

## 已知限制

- 旋转超过约 1 度后读不出。
- 整张纯色或大面积重复花纹的图，被裁剪后无法对齐。
- 调亮到白色溢出的区域，信息会丢失。
- 多个支援者把各自的图对比或平均后，可以削弱甚至抹掉水印。AI 重绘同理。
- 目前按 8 位色处理，16 位色的图会被降到 8 位。
- 没在真实平台（推特、Discord 等）的转码上实测过。
- 网页版只在 Chromium 里测过；带半透明像素的图经过浏览器画布后可能有极小的颜色偏差。
