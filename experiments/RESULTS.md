# 水印算法对比

复现：`python experiments/bench.py --no-solid "blind_watermark" "trustmark" "nonblind a=1" "smooth" && python experiments/report.py`
（测试图放 `experiments/real/`，不入库）。

- 载荷 32 bit，无纠错码；表中数字是比特正确率（%），50 等于瞎猜。
- 除 "no registration" 一行外，所有算法检测前都先用原图把泄露图对齐回原始尺寸。
- 每张图 2 个随机载荷；纯白 1 张、合成 2 张、真实插画 4 张，样本很小。
- `nonblind`：按相对网格分块，每块亮度 ±a 级，检测时减去原图。
- `smooth`：同样的载荷布局，但把方块插值成平滑起伏并用随机抖动取整，没有硬边。`+tex` 表示在有纹理/线条处加大幅度。
- `charcrop`：只保留画面中间一半。

第二轮结论：
1. 平滑图案在真实插画上和方块版一样稳，纯白上 a=1 基本看不出，a=2 隐约有斑。
2. `smooth a=1+tex1` 在真实插画的全部 13 项里只有一项不是 100%（缩到 30% 再 JPEG，98%）。
3. blind_watermark 离开我们的对齐步骤后，任何裁剪都读不出（约 50%）；对齐后在截图和重度缩放上仍弱于自研方案，且改动幅度大得多。
4. 第一轮（含 invisible-watermark 与五种纯色）已淘汰 invisible-watermark。
