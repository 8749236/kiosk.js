# 水印算法对比（第一轮）

复现：`python experiments/bench.py && python experiments/report.py`（测试图放 `experiments/real/`，不入库）。

- 载荷 32 bit，无纠错码；表中数字是比特正确率（%），50 等于瞎猜。
- 所有算法检测前都先用原图把泄露图对齐回原始尺寸。
- 每张图 2 个随机载荷；纯色 5 张、合成 2 张、真实插画 3 张，样本很小。
- `nonblind` 是本仓库自己的方案：按相对网格分块，每块亮度 ±a 级，检测时减去原图。

结论：
1. 现成盲水印库在纯色和大面积平涂上不可靠，改动幅度还更大（最大像素差 20–170）。
2. 非盲方案在除"纯色图裁剪"外的所有项目上基本满分；纯色图裁剪无法对齐，属于原理限制。
3. 未解决：方块边缘在纯色上肉眼可见（a=3 明显，a=1 隐约），需要改成平滑过渡的图案后重测。
